# 시연 대본 (약 3분)

준비: README대로 백엔드(8000)와 프론트(5173)를 띄우고, **시연 모드** 체크를 켠 상태로 시작합니다.
샘플 데이터는 현재 시각 기준으로 만들어지므로, 언제 시연해도 아래 상황이 재현됩니다.

1. **문제 소개 (20초)** — "올림픽공원에서 운동하려 할 때 날씨·미세먼지·사람 많음·행사 정보를 따로 찾아봐야 합니다."
2. **입력 (20초)** — 러닝 / 3km / 저녁 선택 → "오늘 운동 추천 받기".
3. **결과 설명 (60초)**
   - 상단 **DEMO** 배너: "지금 값은 샘플입니다. 실제 관측값이 아닙니다."
   - 최상단 추천 시간과 점수·등급, 추천 이유 목록.
   - "혼잡도는 **공원 전체 기준**이며 코스별 혼잡도가 아닙니다" 문구 짚기.
   - 추천 코스: 목표 3km → 가장 가까운 공식 코스(젊음의 길 3.15km). 공식 경로 요약과 KSPO 안내 링크를 보여줍니다.
4. **안전 우선 규칙 (30초)** — "다른 시간대 보기"를 펼쳐 3시간 뒤 '비' 시간대가 점수가 높아도 **야외운동 비권장**인 것을 보여줍니다. 6시간 뒤 대기질 '나쁨' 시간대는 낮은 등급.
5. **행사·주의 정보 (20초)** — 샘플 공연·공지 카드. "행사는 주의 정보일 뿐, 코스가 붐빈다고 단정하지 않습니다."
6. **출처·한계 (30초)** — 하단 데이터 출처·갱신 시각·면책 문구.
   - 검증된 사실: 공식 코스 이름·거리
   - 가설: 점수 가중치(초기 설계값)
   - 한계: 혼잡도는 공원 단위, 코스 좌표 기반 지도는 미구현, 대기질 시간별 예보 미확보, 실 API 필드 검증 전
7. **(선택) 실데이터 모드** — 시연 모드를 끄면 키가 없을 때 "실시간 데이터를 가져오지 못했습니다"로 안내하고 값을 지어내지 않는 것을 보여줍니다.

마무리 한 문장: **OLPARK RUN은 날씨·대기질·공원 단위 혼잡도와 공연·이용 정보를 운동 목적에 맞춰 묶어, 올림픽공원에서 갈 시간과 코스를 선택하도록 돕는 데이터 기반 운동 가이드다.**
